# 给测试者的说明（Beta）

感谢帮忙试装。这一步只需要你**在一台真实电脑上装一遍**，然后告诉我结果——成功、失败、卡在哪一步，都算有效反馈。

## 一、你的电脑需要

- Windows 10（2004 及以上）或 Windows 11，**64 位**
- 安装过程需要联网，约 2–4.5 GB 磁盘空间
- 建议用**普通家用网络**（不要挂梯子/VPN）。挂着 Clash、v2ray 这类代理时请先关掉，否则可能连不上镜像
- 装完想直接聊天的话，准备一个 **OpenAI 兼容的 API Key**（Base URL + Key + 模型名）。没有也可以先装，之后在程序里补

## 二、下载与校验

- 文件：`Setup.exe`，约 **403 MB**
- SHA256：以发行页上公布的那一串为准（每个构建都不同，别用别处抄来的）
- 校验方法（PowerShell）：`Get-FileHash .\Setup.exe -Algorithm SHA256`，与发行页逐字符对比

## 三、安装

1. 双击 `Setup.exe`。
2. 若弹出 **「Windows 已保护你的电脑」**：点「更多信息」→「仍要运行」。安装包没有代码签名，这是系统的常规提示，不是病毒。
3. 向导四页：**环境预检 → 安装位置 → 安装 → 完成**。
   - 「安装位置」页可以改程序、数据、记忆库三处位置（仅首次安装可选），默认就好。
   - 同页两个勾选：「开机自动启动」（默认勾）、「浏览器与电脑操作」（约 500 MB，默认勾；不想装可以取消，之后能补装）。
4. 安装页会显示进度，正常 **5–15 分钟**（取决于网速）。中途别关窗口；真断了重跑会接着装。
5. 看到 **「安装完成」** 就成功了。点「完成」启动程序，按里面三步走：连接 AI → 绑定微信 → 发第一句话。

## 四、可能遇到的拦截

| 现象 | 处理 |
| --- | --- |
| SmartScreen「未知发布者」 | 更多信息 → 仍要运行（无签名，正常） |
| 杀软报「Trojan/Generic」之类 | 加信任/恢复。单文件自解压 exe 常见误报，可以把文件发我做进一步核对 |
| 安装页停在某个下载不动 | 先确认代理已关；仍不动就把失败页截图发我 |

## 五、装好之后怎么确认

打开程序 → 左下「体检」→ 全部通过即正常。
命令行验证（可选）：`%LOCALAPPDATA%\hermes\bin\hermes.exe --version`，应显示 `Hermes Agent v0.22.2`。

## 六、出问题请发我这些

1. 失败页的**整屏截图**（上面会写失败原因和末尾几行日志）。
2. `%LOCALAPPDATA%\hermes\logs\install.log`（安装日志，最新的那个）。
3. 你的系统版本（`winver` 截图）和是否有代理/杀软。

## 七、已知限制

- 没有代码签名，首次运行必然有一次 SmartScreen 提示。
- 只测过 x64；ARM64 的 Windows 尚未验证。
- 安装器不支持 Windows 7/8。
