# HerMemory 使用指南

你的文档与 AI 的记忆都是普通 Markdown 文件，存放在你自己的记忆库（vault）内。改完保存、开新对话生效，文件可随时带走。

## 日常使用

### 与它对话

在微信里直接说自然语言；也可以在终端执行 `hermes` 对话。微信是主通道；钉钉、飞书等其他通道由上游 gateway 支持，接入方式询问 AI。

它能看到每条消息的真实时间（网关注入），无需你另行说明时间。

常用指令：

| 你说 | 它做 |
| --- | --- |
| 记住这个 | 写入长期记忆 |
| 写今天的日记 / 总结这一周 | 按指令写作 |
| 每天凌晨帮我备份一次 | 建立定时任务并登记 |
| 检查一下模型 | 模型失效时更换为可用型号 |
| 导出全部数据 | 打包记忆库与 AI 端全量 |
| 记忆容量换成标准档 | 调整记忆预算 |
| 把人设文件发我 | 把 `SOUL.md` 的全文发给你 |

### 记忆文件在哪里

记忆库 `HerMemory/memory/` 下五个文件：

| 文件 | 内容 |
| --- | --- |
| MEMORY.md | 它经历过、记住的事 |
| USER.md | 它对你的了解 |
| SOUL.md | 它的性格 |
| AGENTS.md | 它的行为规矩 |
| AUTOMATION.md | 定时任务与自动化登记册 |

用 Obsidian 或任意文本编辑器直接编辑。要让它忘记某事，删除对应行即可；文件属于你。

这些文件同时以**链接**形式接入 AI 的自动加载位置（AGENTS.md 接入 `%USERPROFILE%\.hermes.md`）。你在记忆库里改的就是 AI 读到的那一份，不存在两份副本需要对齐；不要去改动或删除自动加载位置上的文件。

生效三步：编辑文件 → 保存 → 开启新对话。无需重启任何服务。

### 用应用里的编辑器改记忆

主界面点**编辑记忆**（托盘右键也有「编辑记忆…」），会打开应用自带的 Markdown 编辑器：

- 左边列五个记忆文件，右侧是编辑区，再右侧是实时预览（可关掉）。
- `MEMORY.md` / `USER.md` 会显示当前字数与记忆预算，超预算标红——超了不会丢内容，只是 AI 下次写记忆时会先要求自己整合。
- **保存用 Ctrl+S 或「保存」按钮**，写的是记忆库里那份真文件（AI 读的就是它），UTF-8 纯文本、原子替换，写到一半断电也不会把文件写坏。
- 如果文件在你打开期间被改过（AI 自己写了记忆、或你用别的编辑器改过），保存前会问你「覆盖还是重新载入」，不会静默盖掉。
- **历史**按钮给这个文件做本地版本：每次有改动的保存自动留一个快照，可以看差异、一键回滚到某次保存。快照存在本机（`%LOCALAPPDATA%\HerMemory\history`），**不进记忆库**，不会被任何同步工具带走；「一键导出」会把它一起打包，卸载时删除。
- 改完开新对话生效（和以前一样）。

不想用它也行：直接用 Obsidian、记事本编辑同一个文件，效果一样。

### 写作规则

由你明确指令后才写：日记、总结、文章。写作规范：只写事实与你明确表达过的情绪，不编造、不推测、不使用 AI 腔；一天可多次写入，每次在原有内容上更新，不整块覆盖。

## 两项必须知道

### 1. 规矩文件有安全扫描

AGENTS.md 可自由编辑，但上游 Hermes 对其执行威胁扫描：内容含触发词会被整体拦截，你写的规则随之静默失效。新增规则不生效时先检查此项，换一种措辞（含义不变）重新保存。

MEMORY.md 与 USER.md 逐条扫描：命中条目在对话中显示为 `[BLOCKED: ...]`，文件本身不丢失，修改触发词后恢复。

### 2. 自动化默认关闭

它不会自行执行任何操作。日记需你指令后才写；周报、定时任务、主动汇报均不存在，除非你主动提出。提出后它建立定时任务并登记进 `AUTOMATION.md`；该登记册随记忆库迁移，更换设备后照单重建。

## Windows：系统托盘与主界面

程序本体位于 `C:\Program Files\HerMemory`（安装时可改），桌面与开始菜单有快捷方式；装完即常驻系统托盘，全部操作无需命令行。

托盘图标左键打开主界面；右键菜单：启动 / 停止网关、打开日志文件夹、打开主界面、微信绑定、卸载、开机自启（安装向导里默认勾选，可在此关闭）、关闭时最小化到托盘、深色模式、退出。

安装向导的「安装位置」页另有一个**浏览器与电脑操作**勾选框（默认勾选）：网页浏览能力（agent-browser + Chromium）与屏幕操作驱动（cua-driver），合计约 500 MB。取消勾选可让安装快很多、占盘少很多；需要时随时补装：对 AI 说「装上浏览器能力」，或执行 `hermes pm install agent-browser cua-driver`。

主界面分四块：

- **状态卡**：Gateway 状态灯 + 启动 / 停止 / 刷新（在线时「停止」是主按钮，离线时是「启动」）
- **常用功能**（六个磁贴）：记忆设置、API 设置、微信绑定、设置、体检、重置 AI
- **底部动作**：编辑记忆、一键导出、使用文档、打开记忆库、卸载
- **右上角圆形按钮**：切换浅色 / 深色，跟着系统以外的偏好走，记在本机

各部分功能：

- **刷新**：立即重新检查网关状态，无需等待自动刷新。
- **一键导出**：将记忆库、记忆历史快照、AI 端全量备份、恢复指引打包为 zip 存至桌面。AI 运行中也可导出，不会锁库。
- **记忆设置**：查看当前记忆档位（紧凑 / 标准 / 详细 / 自定义）。换档与 AI 对话完成。
- **API 设置**：修改 API 地址与 Key。「检测」验证地址可达，「获取模型列表」更换默认模型。网关运行中也可保存，保存后需停止再启动网关生效。
- **微信绑定**：查看绑定状态，执行绑定、重新绑定或解绑。
- **重置 AI**：清空 AI 的全部记忆，回到首次使用状态，不重装软件。流程是：先停网关 → 备份现有记忆 → 置空 `MEMORY.md` 与 `USER.md`、把 `SOUL.md` 与 `AGENTS.md` 恢复出厂 → 删除对话记录与运行痕迹 → 按原状态重启网关。API Key、微信绑定、内置技能、记忆库里的文档、软件本体都不受影响。
- **打开使用文档 / 打开记忆库**：直达对应文件与文件夹。

PC 形态的固有限制：关机即离线，AI 仅在开机期间在线，定时任务也只在开机期间执行。

服务器 / NAS 形态无图形界面：网关由 systemd 常驻，执行 `hermes gateway start` / `hermes gateway stop`，或直接与 AI 对话。

## 微信绑定与多设备

一个微信同一时刻只能绑定一台 HerMemory（微信官方限制）。

- **首次绑定**：安装时扫码完成。
- **多台设备**：最后扫码者生效。被顶掉的设备无需重装：主界面 → 微信绑定 →「重新绑定」，扫码即夺回。
- **解绑**：仅断开微信通道，本机记忆与文档不受影响，定时任务照常。也可直接对 AI 说「解绑微信」。
- **整机移交**：解绑或重新绑定后由新的微信扫码即可。注意记忆与文档仍属于本机，移交前请先执行一键导出。

## 体检

主界面 → **体检**，逐项检查本机状态，不调用模型：

- Hermes 内核能不能跑、版本是不是本发行版锁定的 v0.22.2
- PM 托管的 Python 环境在不在
- 网关是否在运行
- 开机自启任务是否完好
- 三个记忆注入槽位（`SOUL.md` / `.hermes.md` / `memories\`）有没有断
- 记忆库五个记忆文件是否齐全
- 磁盘剩余空间
- 记忆是否超出预算
- 最近日志里有没有错误

红色项会直接影响使用。能就地修的（启动网关、重装任务、看日志）右边直接给按钮；要重新跑安装包的会明说。

**AI 不回话时先来这里看一眼**，比翻日志快。

## 每日新对话

对着同一个聊天一直聊下去，上下文会越堆越长，token 花得越多、旧信息还会挤掉新的。

主界面 → **设置** → 打开「每天自动开始新对话」，选个时间（默认 04:00）保存即可。到点后 AI 与你的对话会重新开始，下一条消息从零上下文起算。

- 这是**应用层的定时任务**，只在网关运行时执行；PC 关机期间错过的不会补跑。
- 不影响记忆：`MEMORY.md` / `USER.md` 照旧加载，重置的只是对话历史。
- 想立刻开始新对话，还是在微信里发 `/new`。

## 记忆容量

AI 写入记忆有字符预算。预算越大记忆越细，但注意力越分散、token 消耗越高。建议选择 1-2 档。

| 档位 | MEMORY | USER |
| --- | --- | --- |
| 紧凑（默认） | 2200 | 1375 |
| 标准 | 5000 | 3000 |
| 详细 | 10000 | 5000 |
| 自定义 | 100 – 9999999 | 100 – 9999999 |

换档与 AI 对话完成，或执行 `bash memory-size.sh`，开启新对话生效。该预算只约束 AI 写记忆；文件内容进入对话时不截断，你手写多长都完整生效。

## 记忆库

记忆库（vault，默认 `~/vault`）就是一个普通文件夹：你的文档在 `HerMemory/docs/`，AI 的记忆在 `HerMemory/memory/`，全部是明文 Markdown。

它的意义只有一条：**这些是你的文件，不是软件里的数据。**

- 用记事本、Obsidian、VS Code 都能打开改；应用里也自带「编辑记忆」。
- 整个文件夹可以直接拷走，换电脑、换系统、哪天不用 HerMemory 了，文件照样在。
- 要不要备份、要不要放到别的设备、用什么工具放——都由你决定，软件不替你选，也不往任何服务器上传。

AI 每轮对话读取 `HerMemory/memory/` 里的记忆文件；你的文档它不主动翻阅，点名才读。

## 备份与搬家

- **AI 端定时备份**：对 AI 说「每天凌晨帮我备份一次」建立，默认不开。
- **全量导出**：Windows 使用主界面「一键导出」，zip 存至桌面；Linux 在仓库目录执行 `bash export.sh`（需 zip 命令）。包内含记忆库、记忆历史快照、AI 端全量（数据库一致性副本、技能、配置、定时任务，走上游官方 `hermes backup`）、供下一个 AI 读取的恢复指引 README_REBORN。需要 `hermes` CLI 能跑；内核坏到 CLI 起不来时，只能手动拷走记忆库。
- **更换设备**：新设备部署 HerMemory，记忆库放回原位（重跑安装器会重建符号链接），执行 `hermes import` 恢复 AI 端，按 `AUTOMATION.md` 逐条重建定时任务。记忆不在任何厂商服务器上，只在你手中的文件里。

## 常见问题

**它似乎不记得我改的规则。**
先检查安全扫描：AGENTS.md 含触发词会被整体拦截。改措辞后重新保存；仍无效则让 AI 读取四个核心文件，确认是被拦截还是链接断开。

**如何让它彻底忘掉我？**
主界面点「重置 AI」：停网关 → 备份 → 置空 `MEMORY.md` 与 `USER.md`、`SOUL.md` 与 `AGENTS.md` 恢复出厂 → 删除对话记录与运行痕迹（API Key 与微信绑定保留）。也可以手动清空记忆库 `HerMemory/memory/` 下的文件内容——记忆即这些文件，没有隐藏副本（备份除外，见下条）。

**删除的内容备份里还有吗？**
有。备份可恢复误删，也意味着删除的内容在备份中仍然存在。

**AI 不回话或报模型错误。**
多数是模型退役，对它说「检查一下模型」。它自身无法启动时：PC 重新运行安装包 `Setup.exe`（它会检测到已有安装，走一遍向导即可修复），服务器重跑 `bash install.sh`（配置 AI 环节可重选当前可用模型）。

（本条同时是给 AI 的操作指引：收到「检查一下模型」：`hermes config get model.base_url` 取地址，`.env` 中 `HERMES_CUSTOM_*_API_KEY` 取 Key，`curl <地址>/models` 拉取实时列表，按原型号特征选定仍存在的替代，`hermes config set model.default <新型号>`，重启网关后生效，再告知用户已更换。）

**浏览器 / 电脑操作能力没装上，或提示缺依赖。**
v0.22 起依赖由上游包管理器 PM 统一管理，不再随安装包附带。补装某类能力：`hermes pm install agent-browser`（浏览器）、`hermes pm install cua-driver`（屏幕操作）、`hermes pm install --extra messaging`（微信等消息通道）。装坏了让它自检并重建：`hermes pm doctor`，必要时 `hermes pm repair`。

**HerMemory 停止维护了怎么办？**
全部状态是普通 Markdown 加上一个标准导出包。任何能读取这些文件的 agent 都能接管。
