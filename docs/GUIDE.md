# HerMemory 使用指南

> 装完了？这份文档讲日常怎么用。所有内容都是纯文字，你和 AI 都可以读。

## 核心一句话

**你的文档、AI 的记忆，全是普通 Markdown 文件，住在你自己的同步库里。改了就生效，随时能带走。**

## 每天怎么用

### 和它说话

微信、钉钉、飞书扫码接入（见下文「聊天通道」），或者直接在终端跑 `hermes`。对它说人话就行——「帮我写篇日记」「把这个记下来」「整理一下这段笔记」。

### 让它记住

它该记住的会自己记。你也可以明确说「记住这个」。

记忆住在你 vault 的 `HerMemory/memory/` 里，两个文件：
- **MEMORY.md** —— 它经历过、记住的事
- **USER.md** —— 它对你的了解

想让它忘掉什么，直接删那几行。文件是你的。

### 改它的性格和规矩

- **SOUL.md** —— 它是谁、什么性格。改成你喜欢的样子。
- **AGENTS.md** —— 它的行为规矩。可以加自己的规则。

**生效三步**：改完文件 → 同步到 agent 端 → 开新对话。就这么简单，不用重启任何服务。

### 让它写东西

你说一声才写：日记、总结、文章。它写东西的规矩：只陈述事实和你明确表达过的情绪，不编造、不脑补、不用 AI 腔。一天可以写多次，每次在原文上更新，不整块覆盖。

## 两件必须知道的事（出厂如实告知）

### 1. 规矩文件有「安检」

AGENTS.md 可自由编辑，但上游 Hermes 对它做安全扫描——**内容含触发词会被整体拦截，规则静默失效**。规则不生效时，先想到这一条：把措辞改一改（意思不变）再存。MEMORY.md / USER.md 是逐条安检：出问题的条目在对话里显示 `[BLOCKED: ...]`，文件本身不丢，改掉触发词即恢复。

### 2. 自动化默认全关

写日记由你说一声才写。周小结、定时任务、主动汇报——都不存在，除非你开口：直接对它说「每天晚上十点给我写个日总结」，它自己建定时任务并把登记条目写进 `AUTOMATION.md`（这张登记册跟着同步库走，换机器后照着重建即可）。

## 记忆容量

AI 写记忆有字符预算（默认标准档：MEMORY 8000 / USER 5000 字符）。超了它会先整合旧记忆再写新的。想换档：

```bash
bash memory-size.sh
```

紧凑 / 标准 / 宽敞 / 自定义任选，开新对话生效。注意：这个上限只管「它写记忆的预算」；文件内容进对话不做截断，你手写多长的文件都完整生效。

## 多端同步

服务器端的 vault 就是一个 WebDAV 目录（装完那次显示的端口 / 用户名 / 密码）。

**主路径（唯一推荐）：Obsidian + Remotely Save 插件**——手机、PC 用同一款软件、同一套配置。它给你的是**离线副本**：文档存在你自己设备上，没网也能看能改，联网后手动同步合流；Obsidian 本身也是最好的 Markdown 编辑器。

**同步全手动：想同步时，手动点一下**——包括 PC 自己也这样配。

为什么是手动：**手机上的副本就是你的备份**。自动同步会把 AI 端的删除原样传播到手机——PC 上文件没了，手机上跟着没了，备份就失去了意义。手动意味着每一次删除传播都经过你的手。顺带说，手机的定时自动同步在国产系统上本来就不可靠（杀后台），手动反而诚实。

配置步骤（每台设备一次）：
1. 装 Obsidian（手机应用商店 / obsidian.md），打开或新建仓库，选「本地文件夹」随便一个位置——同步下来的文档会住在这里。
2. 设置 → 第三方插件 → 关闭安全模式 → 社区插件市场搜 **Remotely Save** → 安装并启用。
3. Remotely Save 设置里：远程服务选 **WebDAV**，填服务器地址 `http://服务器IP:端口`、用户名、密码。
4. **关闭插件的自动同步选项**，只用手动触发——想同步时点一下 Remotely Save 的同步按钮。

不想装 Obsidian 的应急看法：
- **浏览器**：filebrowser 网页直接看改（无离线副本，没网看不了）
- **Windows / mac**：映射网络驱动器；**iOS「文件」App** 也支持 WebDAV 连接——都是在线直读，应急用

**PC 形态注意**：AI 装在 PC 上时，WebDAV 只在局域网可达（同一 wifi）。出门前手动同步一次，离线副本照常可读可改；改动攒在本地，回家同步时自动合流。要随时随地同步，选服务器 / NAS 形态。

同步健康的检查不用你操心：对 AI 说「体检一下」，它会跑自检（软链、同步目录、空文件、冲突副本都查）。

## 聊天通道

微信 / 钉钉 / 飞书都走上游 Hermes 的 gateway 平台机制，装完已就位（`hermes gateway install`）。各平台的扫码与配置细节见上游文档 `cli-config.yaml.example` 的 `platforms:` 段与 `website/docs/`。HerMemory 不在此复述上游的配置细节——上游怎么配，就怎么配。

## 备份与搬家

- **AI 本体端**：按时间多重备份（装了上游快照机制）。
- **文档端**：vault 本身被你的多端同步复制着。
- **一键全量导出**（不需要 AI 参与，AI 瘫痪也能跑）：在服务器或仓库目录执行

  ```bash
  bash export.sh
  ```

  产出单个 zip 包，内含：文档库（四核心 + 全部用户文档）、agent 端全量（数据库一致性副本 + 所有 skill + 配置 + 定时任务，走上游官方 `hermes backup`）、README_REBORN 恢复指引。服务器上会临时起一个下载链接（无鉴权，取完即关）；PC 上直接存到本地文件夹。
- **换机器**：新机器装好 HerMemory，解包——vault 放回原位（重跑 install.sh 自动建软链），agent 端用 `hermes import` 恢复 hermes-home.zip，脚本和定时任务按 `AUTOMATION.md` 登记册逐条重建。你的记忆不在任何一家的服务器上，就在你手里的文件里。

## 常见问题

**Q：它好像不记得我改的规则？**
先想安检：AGENTS.md 含触发词会整体拦截。改措辞重存。还不行就对它说「体检一下」。

**Q：怎么让它彻底忘掉我？**
删除 vault 里 `HerMemory/memory/` 下的文件内容即可——记忆就是那些文件，没有隐藏副本（备份除外，备份里仍会保留，见下条）。

**Q：删掉的东西备份里还有吗？**
在。备份的意义就是救回误删。这是备份的两面性：它同时意味着「删掉的东西在备份里还活着」。

**Q：HerMemory 停止维护了怎么办？**
你的全部状态是普通 Markdown + 标准导出包。换任何能读这些文件的 agent，你依然是原来的你。
