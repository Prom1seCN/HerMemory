# HerMemory 使用指南

> 装完了？这份文档讲日常怎么用。所有内容都是纯文字，你和 AI 都可以读。

## 先记住一句话

你的文档和 AI 的记忆，全是普通 Markdown 文件，住在你自己的同步库（`~/vault` 文件夹）里。改了就生效，随时能带走。

## 每天怎么用

### 和它说话

微信里说人话就行：「帮我写篇日记」「把这个记下来」「整理一下这段笔记」。也可以在终端跑 `hermes` 直接对话。微信是主通道；钉钉、飞书等其他通道走上游 gateway 机制，接法问 AI。

这些话可以直接说：

| 你说 | 它做 |
| --- | --- |
| 记住这个 | 写进长期记忆 |
| 写今天的日记 / 总结这一周 | 手动触发写作 |
| 每天凌晨帮我备份一次 | 建定时任务，自动登记 |
| 检查一下同步 | AI 核对四核心文件是否齐全 |
| 检查一下模型 | 模型下架或报错时，换上还活着的型号 |
| 导出全部数据 | 打包文档库和 AI 端全量 |
| 记忆容量换成标准档 | 调整记忆预算 |
| 把人设文件发我 | AI 端的文件复制进同步库，跟着同步到你手上 |

### 它的记忆在哪里

同步库 `HerMemory/memory/` 下四个文件：

| 文件 | 内容 |
| --- | --- |
| MEMORY.md | 它经历过、记住的事 |
| USER.md | 它对你的了解 |
| SOUL.md | 它的性格 |
| AGENTS.md | 它的行为规矩 |

用 Obsidian 或任何文本编辑器打开就能改。想让它忘掉什么，删掉那几行就行，文件是你的。

生效三步：改完文件，同步到 AI 端，开新对话。不用重启任何服务。

### 让它写东西

你说一声才写：日记、总结、文章。它写东西守这些规矩：只写事实和你明确表达过的情绪，不编造、不脑补、不用 AI 腔；一天可以写多次，每次在原文上更新，不整块覆盖。

## 两件必须知道的事

### 1. 规矩文件有「安检」

AGENTS.md 可以自由编辑，但上游 Hermes 对它做安全扫描：内容含触发词会被整体拦截，你立的规矩就静默失效了。所以新加的规则不起作用时，先想到这一条，换个措辞（意思不变）再存。MEMORY.md 和 USER.md 是逐条安检：出问题的条目在对话里显示 `[BLOCKED: ...]`，文件本身不丢，改掉触发词就恢复。

### 2. 自动化默认全关

它不会背着你做任何事。日记由你说一声才写；周小结、定时任务、主动汇报，都不存在，除非你开口。开口之后它自己建定时任务，并登记进 `AUTOMATION.md`——这本登记册跟着同步库走，换了机器照单重建就行。

## Windows：系统托盘里的面板

装完后 HerMemory.exe 常驻系统托盘，控制它不需要命令行：

- 左键点托盘图标开主界面；右键出菜单：启动/停止网关、打开日志、微信绑定、安装向导、卸载、开机自启（默认关）、关闭时最小化、深色模式
- 主界面显示网关状态（运行中 = AI 在线），按钮分三行：第一行启动、停止、刷新、一键导出、卸载；第二行记忆设置、API 设置、微信绑定、WebDAV 同步服务；第三行打开使用文档、打开同步库与主题切换
- 刷新：立即重新检查网关状态，不想等自动刷新时用
- 一键导出：把全部记忆（文档库 + AI 端备份 + 恢复指引）打包成一个 zip，存到桌面。换新电脑或留底都用它；AI 开着也能导，不会锁库
- 记忆设置：查看当前记忆档位；换档跟 AI 说
- API 设置：改 API 地址和 Key；地址旁「检测」验可达，填好 Key 后「获取模型列表」换默认模型。网关停止时才能保存，保存后重新启动生效
- 微信绑定：查看绑定状态；绑定、重新绑定、解绑都在这里（见下节）
- WebDAV 同步服务：只显示运行状态；启停跟 AI 说
- 打开使用文档、打开同步库：直达对应文件和文件夹
- 右上角圆钮切换深浅主题，偏好会记住

PC 形态有个物理限制：关机即离线，AI 只在开机期间在线，定时任务也只在开机期间执行。

服务器 / NAS 形态没有面板：网关由 systemd 常驻，启停用 `hermes gateway start / stop`，或者直接跟 AI 说。

## 微信绑定与多台设备

一个微信同一时刻只能绑定一台 HerMemory（微信官方限制）。

- 初次绑定：安装向导扫码即绑定。
- 多台电脑：最后扫码者生效。被顶掉的电脑**不用重装**——主界面 → 微信绑定 → 「重新绑定」，扫码即夺回。
- 解绑：仅断开微信通道，本机记忆与文档不受影响，定时任务照常。也可以直接跟 AI 说「解绑微信」。
- 换人绑定：解绑或重新绑定后，由新的微信扫码即可。注意：记忆与文档仍属于本机主人；整机移交他人，请先用一键导出移交数据。

## 记忆容量

AI 写记忆有字符预算。预算越大记得越细，但注意力也越散、token 越贵，建议选 1-2 档：

| 档位 | MEMORY | USER |
| --- | --- | --- |
| 紧凑（默认） | 2200 | 1375 |
| 标准 | 5000 | 3000 |
| 详细 | 10000 | 5000 |

换档跟 AI 说一声，或运行 `bash memory-size.sh`，开新对话生效。这个预算只管「它写记忆」这件事；文件内容进对话不截断，你手写多长都完整生效。

## 多端同步

### 同步库是什么

装完你会反复听到「同步库」（也叫 vault）。它就是一个普通文件夹（`~/vault`），里面装两样东西：你的全部文档，和 AI 的记忆（`HerMemory/memory/` 四个文件，外加 AUTOMATION 登记册）。全是明文 Markdown，Obsidian 或者记事本打开就能看。

AI 每轮对话读的是 `HerMemory/memory/` 里的记忆文件；你的文档它不主动翻，点名才读。你和 AI 共用这一个文件夹：它往里写记忆，你往里写文档，谁改了什么一目了然。

### 为什么要同步

同步就是让这个文件夹在你的每台设备（手机、PC、平板）上各有一份，保持一致。三个好处：

1. 文件跟人走：出门在手机上翻笔记、改一篇文档，回来点一下同步，改动就到了 AI 端，它开新对话立刻读到；反过来，它记下的新东西同步后你在任何设备都能看、能改。
2. 每台设备就是一份离线备份：服务器挂了、停机不续了、项目停止维护了，文件在你自己的设备上，一个字都丢不了。
3. 删除经过你的手：同步全手动，AI 端删了什么，只有你亲手点同步才会传到你设备上，备份不会被一次误删静默清空。

### 怎么配

AI 端的同步库是一个 WebDAV 目录：部署对话里你定用户名和密码，AI 起服务。

设备端走一条主路径：Obsidian + Remotely Save 插件，手机、PC 同一款软件、同一套配置。

配置每台设备一次。部署时 AI 会发你一条一键配置链接（手机是二维码），点开就自动写入全部参数。手动配也行：装 Obsidian，插件市场装 Remotely Save，远程服务选 WebDAV，填 AI 端地址和账号密码，然后关掉自动同步。

实在不想装 Obsidian 的应急方案：filebrowser 网页、映射网络驱动器、iOS「文件」App。都是在线直读，没网看不了。

PC 形态注意：WebDAV 只在同一局域网可达。PC 上会有两份库，AI 的（`~/vault`）和你的（名字随意，别和 AI 的同名同路径），手动同步让它们对齐。不是实时反而是优点：AI 把它自己的库改坏了，你的副本毫发无损，直到你亲手同步。你的库就是 AI 库的备份。

同步健康不用你操心：对 AI 说「检查一下同步」，它会去核对四核心文件是否齐全、内容是否完好，有问题照实说。

## 备份与搬家

- AI 端定时备份：对它说「每天凌晨帮我备份一次」就建，默认不开
- 文档端：上面说的多端同步，本身就是复制
- 全量导出：在仓库目录跑 `bash export.sh`，得到一个 zip，里面是文档库（四核心 + 全部用户文档）、AI 端全量（数据库一致性副本、skill、配置、定时任务，走上游官方 `hermes backup`）、给下一个 AI 的恢复指引 README_REBORN。AI 瘫痪了它也能跑。服务器上生成临时下载链接（无鉴权，取完即关），PC 直接存本地
- 换机器：新机器装好 HerMemory，同步库放回原位（重跑安装器会自动建软链），`hermes import` 恢复 AI 端，照 AUTOMATION.md 逐条重建定时任务。你的记忆不在任何一家的服务器上，就在你手里的文件里

## 常见问题

**Q：它好像不记得我改的规则？**
先想安检：AGENTS.md 含触发词会被整体拦截。改措辞重存；还不行就让 AI 把四核心文件读一遍，看到底是被拦了还是路径断了。

**Q：怎么让它彻底忘掉我？**
删掉同步库里 `HerMemory/memory/` 下的文件内容。记忆就是那些文件，没有隐藏副本（备份除外，见下条）。

**Q：删掉的东西备份里还有吗？**
在。备份能救回误删，也意味着删掉的东西在备份里还活着。

**Q：AI 突然不回话了 / 报模型错误？**
大概率是模型退役了，对它说「检查一下模型」。它连自己都起不来时：PC 重开 HerMemory.exe 走向导，服务器重跑 `bash install.sh`（配置 AI 那步会重选当前可用的型号）。
（这一条同时是给 AI 的操作指引：收到「检查一下模型」——`hermes config get model.base_url` 拿地址，`.env` 里 `HERMES_CUSTOM_*_API_KEY` 拿 key，`curl <地址>/models` 拉实时列表，按原型号特征选一个还存在的替代，`hermes config set model.default <新型号>`，重启网关后生效，再告诉用户换好了。）

**Q：HerMemory 停止维护了怎么办？**
你的全部状态是普通 Markdown 加一个标准导出包。换任何能读这些文件的 agent，你依然是原来的你。
