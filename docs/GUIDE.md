# HerMemory 使用指南

你的文档与 AI 的记忆都是普通 Markdown 文件，存放在你自己的同步库内。改动即时生效，文件可随时带走。

## 日常使用

### 与它对话

在微信里直接说自然语言；也可以在终端执行 `hermes` 对话。微信是主通道；钉钉、飞书等其他通道由上游 gateway 支持，接入方式询问 AI。

它能看到每条消息的真实时间（网关注入），无需你另行说明时间。

常用指令：

| 你说 | 它做 |
| --- | --- |
| 记住这个 | 写入长期记忆 |
| 写今天的日记 / 总结这一周 | 按指令写作 |
| 每天凌晨帮我备份一次 | 建立定时任务并登记 |
| 检查一下同步 | 核对四核心文件是否齐全完好 |
| 检查一下模型 | 模型失效时更换为可用型号 |
| 导出全部数据 | 打包文档库与 AI 端全量 |
| 记忆容量换成标准档 | 调整记忆预算 |
| 把人设文件发我 | 将 AI 端文件复制进同步库，随同步到达你的设备 |

### 记忆文件在哪里

同步库 `HerMemory/memory/` 下五个文件：

| 文件 | 内容 |
| --- | --- |
| MEMORY.md | 它经历过、记住的事 |
| USER.md | 它对你的了解 |
| SOUL.md | 它的性格 |
| AGENTS.md | 它的行为规矩 |
| AUTOMATION.md | 定时任务与自动化登记册 |

用 Obsidian 或任意文本编辑器直接编辑。要让它忘记某事，删除对应行即可；文件属于你。

这些文件同时以**链接**形式接入 AI 的自动加载位置（AGENTS.md 接入 `%USERPROFILE%\.hermes.md`）。你在同步库里改的就是 AI 读到的那一份，不存在两份副本需要对齐；不要去改动或删除自动加载位置上的文件。

生效三步：编辑文件 → 同步到 AI 端 → 开启新对话。无需重启任何服务。

### 写作规则

由你明确指令后才写：日记、总结、文章。写作规范：只写事实与你明确表达过的情绪，不编造、不推测、不使用 AI 腔；一天可多次写入，每次在原有内容上更新，不整块覆盖。

## 两项必须知道

### 1. 规矩文件有安全扫描

AGENTS.md 可自由编辑，但上游 Hermes 对其执行威胁扫描：内容含触发词会被整体拦截，你写的规则随之静默失效。新增规则不生效时先检查此项，换一种措辞（含义不变）重新保存。

MEMORY.md 与 USER.md 逐条扫描：命中条目在对话中显示为 `[BLOCKED: ...]`，文件本身不丢失，修改触发词后恢复。

### 2. 自动化默认关闭

它不会自行执行任何操作。日记需你指令后才写；周报、定时任务、主动汇报均不存在，除非你主动提出。提出后它建立定时任务并登记进 `AUTOMATION.md`；该登记册随同步库迁移，更换设备后照单重建。

## Windows：系统托盘与主界面

安装后 `HerMemory.exe` 常驻系统托盘，全部操作无需命令行。

托盘图标左键打开主界面；右键菜单：启动 / 停止网关、打开日志文件夹、打开主界面、微信绑定、安装向导、卸载、开机自启（默认关）、关闭时最小化到托盘、深色模式、退出。

主界面按钮分三行：

- 第一行：启动、停止、刷新、一键导出、卸载
- 第二行：记忆设置、API 设置、微信绑定、WebDAV 同步服务
- 第三行：打开使用文档、打开同步库、主题切换

各部分功能：

- **刷新**：立即重新检查网关状态，无需等待自动刷新。
- **一键导出**：将文档库、AI 端全量备份、恢复指引打包为 zip 存至桌面。AI 运行中也可导出，不会锁库。
- **记忆设置**：查看当前记忆档位（紧凑 / 标准 / 详细 / 自定义）。换档与 AI 对话完成。
- **API 设置**：修改 API 地址与 Key。「检测」验证地址可达，「获取模型列表」更换默认模型。网关运行中也可保存，保存后需停止再启动网关生效。
- **微信绑定**：查看绑定状态，执行绑定、重新绑定或解绑。
- **WebDAV 同步服务**：显示服务运行状态。启停与 AI 对话完成。
- **打开使用文档 / 打开同步库**：直达对应文件与文件夹。

PC 形态的固有限制：关机即离线，AI 仅在开机期间在线，定时任务也只在开机期间执行。

服务器 / NAS 形态无图形界面：网关由 systemd 常驻，执行 `hermes gateway start` / `hermes gateway stop`，或直接与 AI 对话。

## 微信绑定与多设备

一个微信同一时刻只能绑定一台 HerMemory（微信官方限制）。

- **首次绑定**：安装向导扫码完成。
- **多台设备**：最后扫码者生效。被顶掉的设备无需重装：主界面 → 微信绑定 →「重新绑定」，扫码即夺回。
- **解绑**：仅断开微信通道，本机记忆与文档不受影响，定时任务照常。也可直接对 AI 说「解绑微信」。
- **整机移交**：解绑或重新绑定后由新的微信扫码即可。注意记忆与文档仍属于本机，移交前请先执行一键导出。

## 记忆容量

AI 写入记忆有字符预算。预算越大记忆越细，但注意力越分散、token 消耗越高。建议选择 1-2 档。

| 档位 | MEMORY | USER |
| --- | --- | --- |
| 紧凑（默认） | 2200 | 1375 |
| 标准 | 5000 | 3000 |
| 详细 | 10000 | 5000 |
| 自定义 | 100 – 9999999 | 100 – 9999999 |

换档与 AI 对话完成，或执行 `bash memory-size.sh`，开启新对话生效。该预算只约束 AI 写记忆；文件内容进入对话时不截断，你手写多长都完整生效。

## 多端同步

### 同步库是什么

安装后你会反复接触「同步库」（vault）：一个普通文件夹（`~/vault`），内含你的全部文档与 AI 的记忆（`HerMemory/memory/`），全部为明文 Markdown。

AI 每轮对话读取 `HerMemory/memory/` 中的记忆文件；你的文档它不主动翻阅，点名才读。你与 AI 共用这一个文件夹：它写记忆，你写文档。

### 为什么同步

同步使该文件夹在你的每台设备（手机、PC、平板）各有一份并保持一致。三个作用：

1. **文件跟人走**：在手机上修改文档，同步后 AI 端即读到；AI 记下的新内容同步后你在任意设备可见可改。
2. **每台设备即一份离线备份**：服务停止、项目终止，文件仍在你手中。
3. **删除需经你确认**：同步全手动，AI 端的删除只有你手动同步时才传到你的设备，备份不会被一次误删静默清空。

### 怎么配

AI 端同步库是一个 WebDAV 目录：部署对话中由你设定用户名与密码，AI 启动服务。

设备端使用 Obsidian + Remotely Save 插件，手机与 PC 同一套配置。每台设备配置一次：部署时 AI 会发送一键配置链接（手机为二维码），点开即写入全部参数。手动配置方式：安装 Obsidian，在插件市场安装 Remotely Save，远程服务选择 WebDAV，填入 AI 端地址与账号密码，然后关闭自动同步。

无 Obsidian 时的替代方案：filebrowser 网页、映射网络驱动器、iOS「文件」App。均为在线直读，离线不可用。

PC 形态注意：WebDAV 仅在同一局域网可达。PC 上会有两份库：AI 的（`~/vault`）与你的（名称自定，避开与 AI 相同的路径），由你手动同步对齐。两份副本是特性而非冗余：AI 的库出任何问题，你的副本独立幸存，直至你手动同步。

同步健康无需自查：对 AI 说「检查一下同步」，它会核对四核心文件是否齐全、内容是否完好，并如实报告。

## 备份与搬家

- **AI 端定时备份**：对 AI 说「每天凌晨帮我备份一次」建立，默认不开。
- **文档端**：多端同步本身即复制。
- **全量导出**：Windows 使用主界面「一键导出」，zip 存至桌面；Linux 在仓库目录执行 `bash export.sh`（需 zip 命令）。包内含文档库、AI 端全量（数据库一致性副本、技能、配置、定时任务，走上游官方 `hermes backup`）、供下一个 AI 读取的恢复指引 README_REBORN。AI 故障时仍可导出。
- **更换设备**：新设备部署 HerMemory，同步库放回原位（重跑安装器会重建符号链接），执行 `hermes import` 恢复 AI 端，按 `AUTOMATION.md` 逐条重建定时任务。记忆不在任何厂商服务器上，只在你手中的文件里。

## 常见问题

**它似乎不记得我改的规则。**
先检查安全扫描：AGENTS.md 含触发词会被整体拦截。改措辞后重新保存；仍无效则让 AI 读取四个核心文件，确认是被拦截还是链接断开。

**如何让它彻底忘掉我？**
删除同步库 `HerMemory/memory/` 下的文件内容。记忆即这些文件，没有隐藏副本（备份除外，见下条）。

**删除的内容备份里还有吗？**
有。备份可恢复误删，也意味着删除的内容在备份中仍然存在。

**AI 不回话或报模型错误。**
多数是模型退役，对它说「检查一下模型」。它自身无法启动时：PC 重新运行 `HerMemory.exe` 走向导，服务器重跑 `bash install.sh`（配置 AI 环节可重选当前可用模型）。

（本条同时是给 AI 的操作指引：收到「检查一下模型」：`hermes config get model.base_url` 取地址，`.env` 中 `HERMES_CUSTOM_*_API_KEY` 取 Key，`curl <地址>/models` 拉取实时列表，按原型号特征选定仍存在的替代，`hermes config set model.default <新型号>`，重启网关后生效，再告知用户已更换。）

**HerMemory 停止维护了怎么办？**
全部状态是普通 Markdown 加上一个标准导出包。任何能读取这些文件的 agent 都能接管。
