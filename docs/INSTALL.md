# HerMemory 部署指南

> 一边安装一边看这份文档。安装器每一步在做什么、会问你什么、失败了怎么办，都在这里。
> 机器在跑读条的时候，就是你往下读的时候。

## 开始之前

- 一台 Linux 机器：云服务器、NAS、或 Docker 容器（Ubuntu 22/24 均可）。
- 一个普通用户账号（不要用 root 跑安装器），有 sudo 权限更好（设时区用，没有也能装）。
- 已装 `git` 和 `curl`。缺就先装：`sudo apt install git curl`。
- 不需要提前准备 API key——装完再配（见文末）。

## 开始安装

```bash
git clone https://github.com/Prom1seCN/HerMemory.git
cd HerMemory
bash install.sh
```

## 安装器会做的事，逐条对照

| # | 屏幕上会看到 | 它在做什么 | 你需要做什么 |
|---|---|---|---|
| 1 | 询问 vault 路径 | vault = 同步根：你的所有文档 + 四核心文件住的地方 | 直接回车用默认 `~/HerMemory-vault`，或输入自定义路径 |
| 2 | clone 上游 Hermes | 拉取官方代码，锁定版本 v2026.8.31（版本契约） | 等待。这就是你正在看文档的原因 |
| 3 | 运行官方 setup | 创建 Python 环境、装依赖、生成 `hermes` 命令。首次 1-5 分钟 | 继续往下读 |
| 4 | 铺出厂文件 | 把 MEMORY / USER / SOUL / AGENTS / AUTOMATION 五个文件放进 vault 的 `HerMemory/memory/`。**已存在的文件一律跳过，绝不覆盖**——那可能是你的记忆 | 无 |
| 5 | 建软链 | 把 vault 里的四个文件链接进 agent 的读取位置。agent 读的就是你改的那个文件 | 无 |
| 6 | 皮肤 | 装 HerMemory 主题 | 无 |
| 7 | 时区 | 设为 Asia/Shanghai（时钟错，时间感知就全错） | 可能要输一次 sudo 密码；失败不致命，文末有补救 |
| 8 | 时间注入开关 | 打开官方开关：你的每条消息自动带上服务器真实时间，AI 不靠自觉知道现在几点 | 无 |
| 9 | **询问记忆档位** | 设 AI 写记忆的容量预算（紧凑 2200 / 标准 8000 / 宽敞 20000 字符） | 选一档。拿不准就选标准；以后随时可改 |
| 10 | gateway 服务 | 安装后台服务：微信等聊天通道 + 定时任务都靠它 | 无 |
| 11 | WebDAV 一键同步 | 生成随机密码并**只显示这一次**，起一个同步服务 | **拿手机拍下这行**：端口、用户名、密码 |
| 12 | 自检脚本 | 装好体检工具，以后说「体检一下」就能查同步健康 | 无 |
| 13 | 完成提示 | 两件必须知道的事（见下方） | 读完 |

## 失败了怎么办

- **uv / 依赖下载失败**：网络问题。重跑 `bash install.sh` 即可，装过的步骤会自动跳过。
- **时区设置失败**：没有 sudo。可跳过，稍后手动：`sudo timedatectl set-timezone Asia/Shanghai`。
- **WebDAV 被跳过**：机器上没有 rclone。装好再重跑安装器即可补上：`sudo apt install rclone`。
- **gateway 安装失败**：不影响本体。聊天通道和定时任务可后补：`hermes gateway install`。
- **任何一步卡死**：Ctrl+C 中断，重跑安装器。已完成的步骤不会重做、不会覆盖你的文件。

## 装完第一件事

```bash
hermes setup
```

这是上游官方的 API key 配置向导——也是唯一的 key 配置流程，HerMemory 不代配、不引导、不加自己的花样。

然后运行 `hermes` 开始第一次对话：它会主动认识你（怎么称呼、主要用途、喜欢什么说话方式），并把这些写进它自己的档案。
