# HerMemory 部署指南

> 一边安装一边看这份文档。安装器每一步在做什么、会问你什么、失败了怎么办，都在这里。
> 机器在跑读条的时候，就是你往下读的时候。

## 开始之前

**服务器 / NAS（Linux）**：

- 一台 Linux 机器：云服务器、NAS、或 Docker 容器（Ubuntu 22/24 均可）
- 一个普通用户账号（不要用 root 跑安装器），有 sudo 权限更好（设时区用，没有也能装）。
- 已装 `git` 和 `curl`。缺就先装：`sudo apt install git curl`。

**Windows PC**：

- Windows 10/11，管理员权限或开发者模式（建软链需要，安装器会提示）
- 已装 [Git for Windows](https://git-scm.com/download/win)（安装时一路默认，自带 Git Bash）和 Python 3.10+。缺就装：`winget install Git.Git Python.Python.3.12`
- 同样不需要提前准备 API key。

## 开始安装

**服务器 / NAS（Linux）**：

```bash
git clone https://github.com/Prom1seCN/HerMemory.git
cd HerMemory
bash install.sh
```

**Windows PC**：克隆仓库后双击 `install.bat`（没有 .bat 时，在 PowerShell 里执行 `install.ps1`）：

```powershell
git clone https://github.com/Prom1seCN/HerMemory.git
cd HerMemory
powershell -ExecutionPolicy Bypass -File install.ps1
```

## 安装器会做的事，逐条对照

| #   | 屏幕上会看到          | 它在做什么                                                                                | 你需要做什么                     |
| --- | --------------- | ------------------------------------------------------------------------------------ | -------------------------- |
| 1   | vault 定名        | vault = 同步根：你的所有文档 + 记忆文件住的地方，固定为 `~/vault`                                          | 无需操作                       |
| 2   | 拉取上游 + 官方 setup | 克隆 Hermes 官方代码（锁定版本 v2026.8.31）并安装运行环境。首次 1-5 分钟                                     | 等待。这就是你正在看文档的原因            |
| 3   | 铺出厂文件           | 把记忆、人格、规矩等出厂文件放进 vault 的 `HerMemory/memory/`，使用文档也一并放入。**已存在的文件一律跳过，绝不覆盖**——那可能是你的记忆 | 无                          |
| 4   | 建软链             | 把 vault 里的文件链接进 AI 的读取位置——AI 读的就是你改的那个文件                                             | 无                          |
| 5   | 皮肤              | 装 HerMemory 主题                                                                       | 无                          |
| 6   | 时区              | 设为 Asia/Shanghai（时钟错，时间感知就全错）                                                        | 可能要输一次 sudo 密码；失败不致命，文末有补救 |
| 7   | 时间注入开关          | 打开官方开关：你的每条消息自动带上真实时间，AI 不靠自觉知道现在几点                                                  | 无                          |
| 8   | **询问记忆档位**      | 设 AI 写记忆的容量预算（紧凑 2200 / 标准 8000 / 宽敞 20000 字符）                                       | 选一档。拿不准就选标准；以后随时可改         |
| 9   | **配置 AI**       | API key 引导（见下文），当场验活                                                                 | 见下文                        |
| 10  | gateway 服务      | 安装后台服务：微信等聊天通道 + 定时任务都靠它                                                             | 无                          |
| 11  | 自检脚本            | 装好体检工具，以后说「体检一下」就能查同步健康                                                              | 无                          |
| 12  | 完成提示            | 两件必须知道的事                                                                             | 读完                         |

## 配置 AI（脚本内完成）

安装器会引导你配置 API key，全程只有选择题和一次粘贴：

- **已有 key**：从来源菜单选你的服务商（阿里云百炼 / 腾讯云混元 / 硅基流动 / 其他），粘贴 key——**地址自动填好**，脚本自动测试连通，通了才继续。key 粘错、地址错、余额为零，当场用中文告诉你哪有问题。
- **没有 key**：选「我还没有 key」，脚本会打印免费额度领取指引（三家任选，浏览器里完成注册 → 领额度 → 创建 key），拿到后回来粘贴。

配置完成，**HerMemory AI 就上线了**。

## 装完之后

1. 运行 `hermes` 开始第一次对话——它会主动认识你（怎么称呼、主要用途、喜欢什么说话方式），写进自己的档案。
2. 之后把「**部署待办**」发给它：AI 会按自己的部署手册自动完成模型配置优化、微信接入、同步服务部署，并一步步引导你。你只需要跟着它的话做。

装完之后怎么用：看 **[GUIDE.md](GUIDE.md)**。
