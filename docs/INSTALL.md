# HerMemory 部署指南

HerMemory. Your memory.

安装花 5-10 分钟，中途只需要你做三个决定：选记忆档位、贴 API 地址和 Key、扫微信码。其余安装器自动完成。

## 开始之前

**Windows PC**

- Windows 10/11
- 只需要 `HerMemory.exe` 一个文件：无需其他安装文件，也无需预装 git、Python 等任何工具（安装器自动携带便携版运行环境）
- 安装时能连上 GitHub（内核从那里下载；日常使用不需要，装完就可以断。连不上就先开一次代理）
- 管理员权限或开发者模式（建软链需要；设置 → 更新与安全 → 开发者选项）

**服务器 / NAS（Linux）**

- Ubuntu 22/24 或主流 NAS
- 普通用户账号（不要用 root 跑安装器）
- 已装 git 和 curl：`sudo apt install git curl`

API key 不用提前准备，安装流程会引导你填。HerMemory 不指定服务商：任何 OpenAI 兼容接口的地址和 Key 都行，各家控制台一般都有免费额度。

## 安装

**Windows PC**：下载 `HerMemory.exe` 后双击，跟着向导走：环境预检 → 记忆档位 → 配置 AI → 微信扫码（二维码页面自动打开）→ 完成。全程无命令行窗口，不依赖任何其他文件。装好后常驻系统托盘，启动、停止、刷新、一键导出都在主界面。

**服务器 / NAS（Linux）**：

```bash
git clone https://github.com/Prom1seCN/HerMemory.git
cd HerMemory
bash install.sh
```

中途断了不用慌：重新运行，已完成的步骤自动跳过。

## 安装器做了什么（对照屏幕）

| 步骤 | 它在做什么 | 你要做什么 |
| --- | --- | --- |
| 1 | 建同步库 `~/vault`：一个普通文件夹，你的文档和 AI 的记忆都住这里 | 无 |
| 2 | 拉取 Hermes 官方内核（锁定 v2026.8.31）并安装运行环境 | 等待 |
| 3 | 铺出厂文件：记忆四核心 + 使用文档放进同步库；已存在的一律跳过，绝不覆盖 | 无 |
| 4 | 建软链：从此 AI 读写的就是你同步库里的那份文件 | 无 |
| 5 | 装皮肤、设时区 Asia/Shanghai、打开时间注入（你的每条消息自动带真实时间） | 可能输一次 sudo 密码 |
| 6 | 选记忆档位：紧凑 2200/1375（默认）/ 标准 5000/3000 / 详细 10000/5000 | 选一档；拿不准选紧凑，以后随时改 |
| 7 | 配置 AI：地址 → Key → 从实时模型列表选默认，当场验活 | 两次输入一次选择，见下文 |
| 8 | 微信扫码：打开英文向导，照屏幕上的中文答题卡操作 | 扫码并确认 |
| 9 | 装网关服务：微信通道和定时任务都靠它，登录自启 | 无 |
| 10 | 放好自检脚本，打印完成提示 | 读一眼 |

## 配置 AI（在安装流程里完成）

三个输入：

1. **API 地址**：服务商控制台里的 OpenAI 兼容地址，一般以 `/v1` 结尾
2. **API Key**：同一控制台生成，明文粘贴，方便核对
3. **默认模型**：安装器实时拉取该地址的模型列表，输序号选一个，列表里的都是当前活着的型号

当场验活：key 不对、地址不通、名下没有可用模型，都会用中文告诉你是哪一步的问题，改完重试，不限次数。复制粘贴混进的隐形字符会被自动清掉。

## 装完之后

打开微信，给 AI 发第一句话（安装时扫过码）。它会自我介绍、认识你（怎么称呼、主要用途、喜欢什么说话方式，写进 USER.md），然后按它自己的部署手册引导你完成剩下的：起同步服务、配好你的设备、演示一遍它能做什么。你只管跟着它的话做。

没接微信也行：终端跑 `hermes`，开始同样的对话。

日常怎么用：看 **[GUIDE.md](GUIDE.md)**。

## 卸载

**Windows**：`HerMemory.exe`，主界面「卸载」或托盘右键「卸载…」。移除内核与配置、微信凭据、网关任务与登录项、自启注册表、偏好设置。同步库默认保留：里面是你的文档与记忆，是资产不是软件痕迹；要全部抹除需勾选并二次确认。可顺带删除 exe 自身，仓库和下载源不受影响。

**Linux**：

```bash
hermes gateway stop 2>/dev/null
rm -rf ~/.config/systemd/user/*hermes* && systemctl --user daemon-reload
rm -rf ~/.hermes ~/hermes-agent ~/.hermes.md
```

同步库（`~/vault`）想删自己删。卸载后重装：重新运行安装即可，一切从零开始。
