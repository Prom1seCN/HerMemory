# HerMemory 部署指南

HerMemory. Your memory.

安装包一次完成全部部署：Hermes 内核、记忆库、微信通道、网关服务。向导先让你选安装位置并装好运行环境，再填记忆档位与 API，最后扫码接入微信。

## 准备条件

**Windows PC**

- Windows 10 / 11
- 只需要安装包 `Setup.exe` 一个文件，无需预装 git、Python、Node 等任何工具（内核源码与 uv 已内嵌）
- **安装过程中需要联网**：Python 3.14、Node、Chromium（可选）与 Python 依赖由安装器现场下载，走官方 sha256 镜像与国内源（清华 PyPI / npmmirror）
- 需要同意一次管理员授权（向导预检阶段弹出，用于创建符号链接与写入程序目录）。已开启开发者模式（设置 → 更新与安全 → 开发者选项）时不会因符号链接而请求提权
- 默认装到 `C:\Program Files\HerMemory`（几十 MB，程序本体），运行时与数据放在 `%LOCALAPPDATA%\hermes`。两者的位置都能在向导的「安装位置」页改，**仅首次安装可选**
- 磁盘占用随「浏览器与电脑操作」勾选变化：勾选约 3.5–4.5 GB，不勾约 2–2.5 GB。建议预留 6 GB。数据位置所在磁盘剩余不足 3 GB、或程序位置所在磁盘不足 1 GB 时，该位置会被拒绝并说明原因

**服务器 / NAS（Linux）**

- Ubuntu 22 / 24 或主流 NAS
- 普通用户账号（安装器拒绝以 root 运行）
- 已装 git 与 curl：`sudo apt install git curl`
- 需要可访问 GitHub 与 PyPI（内核与依赖由上游安装器现场取；把 `hermes-agent.bundle` 放在仓库根可免 clone）
- 安装过程中需要输入一次 sudo 密码

API 地址与 Key 不必提前准备，安装流程会引导填写。HerMemory 不指定服务商：任何 OpenAI 兼容接口均可。

## 安装

**Windows PC**

双击 `Setup.exe`，向导共六页：环境预检 → 安装位置 → 安装 → 记忆档位与 AI 配置 → 微信扫码 → 完成。

「安装位置」页可分别指定程序位置与数据位置，并有两个勾选框：**开机自动启动**（默认勾）与**浏览器与电脑操作**（默认勾，约 500 MB：网页浏览能力与屏幕操作驱动）。取消后者可省下大部分体积，代价是这两类技能暂时不可用——之后随时能补装：`hermes pm install agent-browser cua-driver`。

**位置仅首次安装可选**——检测到已有安装时该页只读，需更换位置请先卸载再重装。安装页实时显示进度并支持中止；中断后重新运行，已完成步骤自动跳过。全程无命令行窗口。

安装完成后桌面与开始菜单会生成快捷方式，程序常驻系统托盘，日常操作在主界面完成。**你手上那个安装包就是唯一副本**——需要修复或重装时重新运行它即可。

**服务器 / NAS（Linux）**

```bash
git clone https://github.com/Prom1seCN/HerMemory.git
cd HerMemory
bash install.sh
```

同样支持中断续装。

## 安装器做的事

| 步骤 | 动作 | 你需要做 |
| --- | --- | --- |
| 1 | 落位 Hermes 官方内核（锁定 v0.22.2，上游 d923a5e 的工作树）：从随包 git bundle 检出，零网络 | 等待 |
| 2 | 由上游 PM 装运行环境：Python 3.14、Node、工具二进制与 Python 依赖（全部按 `pm/lock.json` 的 sha256 校验） | 等待，需联网 |
| 3 | 建立同步库 `~/vault`：普通文件夹，用户文档与 AI 记忆都在其中 | 无 |
| 4 | 铺出厂五文件：MEMORY / USER / SOUL / AGENTS / AUTOMATION。已存在的文件一律跳过，不覆盖 | 无 |
| 5 | 将使用文档（`docs/`）放入同步库，供用户与 AI 共同读取 | 无 |
| 6 | 建立符号链接：AI 读写的就是同步库中的那份文件 | 无 |
| 7 | 安装品牌皮肤、设定时区（Asia/Shanghai）、开启消息时间注入与中文界面 | 无 |
| 8 | 设置记忆档位 | 在向导中选择 |
| 9 | 配置 AI：验证地址 → 验证 Key → 从实时模型列表选定默认模型 | 两次输入、一次选择 |
| 10 | 微信扫码接入（可跳过） | 扫码确认 |
| 11 | 注册网关服务：微信通道与定时任务依赖它；是否随登录自启由向导中的勾选项决定（默认开启） | 无 |
| 12 | 把程序本体释放到安装位置、生成桌面与开始菜单快捷方式、登记卸载入口 | 无 |

## 配置 AI

1. **API 地址**：服务商的 OpenAI 兼容地址，一般以 `/v1` 结尾
2. **API Key**：在同一控制台生成，明文粘贴便于核对
3. **默认模型**：安装器实时拉取该地址的模型列表，输入序号选择

三项均当场验证：地址不可达、Key 未通过、名下无可用模型，都会指明具体原因，可反复重试。粘贴带入的不可见字符会被自动清除。

## 装完之后

**已接入微信**：打开微信向 AI 发送第一条消息。它会自我介绍，向你了解称呼、用途与表达偏好并写入 USER.md，随后按其部署手册（`docs/ONBOARDING.md`）引导完成剩余配置：同步服务、多端接入、能力演示。

**未接入微信**：终端执行 `hermes`，开始同样的对话。

日常使用见 [GUIDE.md](GUIDE.md)。

## 卸载

**Windows**：从「设置 → 应用」或「控制面板 → 程序和功能」里卸载（列表项名为 `HerMemory`），也可从程序主界面「卸载」或托盘右键「卸载…」发起。移除内容：Hermes 内核与运行数据、微信接入凭据、网关计划任务与登录项、开机自启项、偏好设置、桌面与开始菜单快捷方式、程序目录。卸载前先停止网关；卸载过程需要一次管理员授权。

同步库默认保留，其中是用户文档与记忆，属资产而非软件痕迹；需一并删除时勾选对应选项并二次确认。

**Linux**：

```bash
hermes gateway stop 2>/dev/null
rm -rf ~/.config/systemd/user/*hermes* && systemctl --user daemon-reload
rm -rf ~/.hermes ~/hermes-agent ~/.hermes.md
```

同步库（`~/vault`）按需自行删除。重新运行安装器即可重新部署。
