## v0.1.0（基于 Hermes Agent v0.21.0，tag v2026.8.31）

首个发行版。出厂默认层（相对上游 Hermes 的差异）：

- **memory/技能/设置全进同步库**：`~/.hermes` 侧全部为指向 vault 的符号链接，可查看 + 改完生效（热更新）
- **时间双重优化**：上下文注入 Asia/Shanghai 当前时间 + 「先看时间再作答」规则置顶
- **新闻时效对比**：讨论新闻/模型前先对比发布时间
- **read-before-write**：写前必读最新版，防三方并发覆盖
- **出厂默认记忆骨架**：USER.md 三节引导结构 + MEMORY.md § 格式 + 使用规则.md 行为规则体
- **记忆压缩协议**：容量/久远双触发，正文归档 `旧档/`，注入层只留指针
- **出厂默认单库**：开箱一个同步库；拆库为按需 skill（触发：文件上百 / Sync 超 3 秒）
- **冷启动**：首启采档案对话（第一天认识你）；日记默认自动（可关）；免费 API key 引导自领（Nous Portal）
- **品牌皮肤**：`skins/hermemory.yaml`（官方皮肤机制，一个文件换横幅与名字口径）
- **双层分账**：软件零商业动作——无购买提示、无套餐弹窗；变现全部在成诺记忆服务层

未入列（候选池，等触发）：快照恢复对话化 / 装机预热+验收卡 / 断链感知 / 遗忘权对话化 / 搬迁机制。
