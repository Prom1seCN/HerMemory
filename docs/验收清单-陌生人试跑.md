# 陌生人试跑验收清单

> 目的：验证「一个没用过的人，能不能自己装到微信能说话」。
> 判据只有一条：**装机完成线 = 微信能说话**。
> 每个 ❌ 都是一个真实的放弃点，记下来，不要现场修。

## 0. 前置

- [ ] 干净的 Windows 10/11（虚拟机或 Windows Sandbox）
- [ ] 没有装过 HerMemory、没有 `C:\Program Files\HerMemory`
- [ ] 没有 Python / Node / uv
- [ ] 网络：家用宽带，**不开代理**
- [ ] 计时器开始

## 1. 下载

- [ ] 打开 `https://github.com/Prom1seCN/HerMemory/releases/latest`
- [ ] 找到 `Setup.exe`，能看懂该下哪个
- [ ] 下载完成
- [ ] **记录**：文件大小 ____ MB，耗时 ____ 分钟

> 当前风险：latest 指向 `HerMemory`（v0.1.0，253.6 MB）。0.3.0 从未发布。
> 发布 0.3.0 前必须先确认体积没有把陌生人吓退（422 MB 是 v1.0 的 1.7 倍）。

## 2. 启动安装器

- [ ] 双击 `Setup.exe`
- [ ] 有 UAC 提示，点「是」
- [ ] **3 秒内出现窗口**（不是只有托盘图标）
- [ ] 窗口标题是 `HerMemory`

> 失败判据：双击后桌面什么都没有、只在托盘出现图标 → 发的是 `shell-lite` 托盘壳，直接判定失败。

## 3. 欢迎页

- [ ] 看到欢迎页，知道下一步点什么
- [ ] 没有看不懂的术语

## 4. 安装位置

- [ ] 默认路径可以一路下一步（不需要理解「程序位置」vs「数据位置」）
- [ ] 如果改了路径，有明确提示

## 5. 安装过程

- [ ] 有进度显示，不是黑屏或长时间无响应
- [ ] **记录**：安装耗时 ____ 分钟
- [ ] 中途没有报错弹窗
- [ ] 没有要求打开代理

> 当前实测：真机 0.22.2→0.3.0 升级 795 秒（13 分 15 秒）。
> 干净安装预计更久。超过 20 分钟应视为失败。

## 6. 完成页

- [ ] 明确告诉用户「接下来做什么」
- [ ] 点「完成」后**程序自动启动**
- [ ] 不需要自己去开始菜单找

> 当前实现：`BtnFinish_Click` 会 `LaunchInstalledApp()`，符合。

## 7. 配置向导（最关键）

- [ ] 程序启动后**自动进入三步配置**，不是停在托盘
- [ ] 第一步：能填 API 地址 + Key + 选模型
- [ ] 填错时有明确提示，不是英文报错
- [ ] 第二步：出现微信二维码
- [ ] 微信扫码成功
- [ ] 第三步：提示发第一句话

> 失败判据：启动后无窗口 → `shell-lite` 壳，或 `HermesCtl.Installed` 判断异常。

## 8. 微信验收（完成线）

- [ ] 微信里出现 AI 的对话
- [ ] 发「你好」，**30 秒内**有回复
- [ ] 回复是中文
- [ ] AI 知道自己的名字是 HerMemory

## 9. 重启存活

- [ ] 重启电脑
- [ ] 不点任何东西，直接在微信发消息
- [ ] 有回复（gateway 开机自启生效）

## 10. 记忆验收

- [ ] 微信里说「记住我喜欢喝美式」
- [ ] 打开 `%USERPROFILE%\vault\HerMemory\memory\MEMORY.md`
- [ ] 能看到这条记录
- [ ] 手动改一个错别字，保存
- [ ] 微信说「开新对话」，再问「我喜欢喝什么」
- [ ] 回答正确（说明用户编辑生效）

## 已知问题（发布前必须修）

1. **`shell-lite` 是默认产物的话，陌生人 100% 用不了**——没有配置界面。
   `build-release.ps1` 已改为默认 `shell/`，但 `Setup.exe` 未重打。
2. **0.3.0 从未发布**，GitHub latest 仍指向 v0.1.0（253.6 MB）。
3. README 的 `Hermes-v0.22.2` badge 与实际内核 0.23.0 不符。
