# HerMemory 0.3 规划：EXE 当控制台，微信当使用面

> 一句话：用户只点 EXE 装和管；所有日常对话都在微信里。上游 0.22 的能力按这个分工重新包装，
> 不做桌面聊天、不做终端、不做 dashboard。

## 1. 现状（已核实）

- **安装向导**：欢迎 → 安装/数据/记忆位置 → API 与记忆 → 微信扫码 → 完成。配置塞在安装流程里，
  跳过或失败后没有第二次机会。
- **应用**：状态卡、启停、记忆编辑器、导出、体检、明暗、托盘、更新提示（只跳浏览器）。
- **内核 0.22.2**：CLI 齐全 —— `plugins`（install/remove/enable/show/capabilities/check-updates）、
  `skills`、`model`、`usage`、`sessions prune`、`tools`、`security`、`backup`、`logs`。
- **插件目录是本地资产**：`<内核>\plugin-catalog\*.yaml` 共 615 条，字段 name/repo/sha/description/
  maintainer/tier/category/requires_hermes/version/capabilities/requires_env/platforms。
  分类分布：tools 184、desktop 141、memory 65、models 51、general 45、automation 39、web 34、platform 32、voice 18。
  安装按 40 位 commit SHA 固定，命令可非交互：`plugins install <name> --yes-deps --enable`。
- 插件位置：内置 `<内核>\plugins`；用户装的在 `%LOCALAPPDATA%\hermes\plugins`。
  内核自带 git：`%LOCALAPPDATA%\hermes\git\bin\git.exe`。
- **聊天侧已有引导**：`docs/ONBOARDING.md` 规定 AI 在微信里怎么带用户走第一轮（自我介绍、写第一条记忆、
  让用户亲手改 AGENTS.md）。这部分不重复做。

## 2. 取舍表（0.22 能力 → 我们要不要 → 我们的形式）

| 上游能力 | 采用 | 我们的形式 |
|---|---|---|
| 首次启动引导（桌面聊天式） | ✅ 改造 | 应用内 3 步：给大脑 / 接微信 / 试第一句；"认识你"留在微信第一轮 |
| 免费试用模型 `nous/welcome` | ⚠️ 不自带 | 自建试用中转（可选），不用 Nous 匿名身份 |
| 插件市场（600+） | ✅ | 精选货架 30–50 个，中文说明 + 权限与数据去向披露 |
| 技能（skills） | ✅ 先上 | 纯文本、无依赖，比插件安全，适合当第一个"扩展" |
| 一键本地模型 | ⏳ P2 | 「离线模式（实验）」：检测显存/内存，按需下载 |
| 模型选择器 + 额度 | ✅ | 「模型与额度」页：预设国内 provider、测通、余额/限流、推荐 |
| 稳定通道 + 原子更新 | ✅ | 应用内更新：下载 → 校验 sha256 → 静默升级 → 保留记忆 |
| 会话自动清理 | ✅ | 设置项 + 立即清理 + 占用展示 |

| Connectors / Bot Screen / 桌面端 / i18n | ❌ | 与微信场景无关，不做 |

## 3. 安装与首次启动

**安装向导收敛成"只装"**：欢迎 → 位置 → 安装进度 → 完成（勾选"立即启动"）。
模型、微信、试用全部搬到应用里，理由：安装器里做扫码/测 Key 失败率高，且不可重进。

**首次启动 3 步（可跳过、可从设置重进）**

1. **给它一个大脑**
   - 三个入口：`免费试用`（若开）/ `用我的 Key` / `本地模型（稍后）`。
   - Key 入口给预设：DeepSeek、通义千问、Kimi、智谱、OpenRouter、自定义（base_url + model）。
   - 「测试」= 发一个最短请求，回来显示 `✓ 可用 · 0.8s · 模型 deepseek-chat`。
   - 失败要给人话：Key 错 / 没网 / 余额不足 / 模型名不对。
2. **接到微信**
   - 扫码 → 显示「已连接：微信昵称」。
   - 补一句安全说明：只有这个微信会给 AI 发指令。
3. **试第一句**
   - 页面给一句可复制的话：「你好，我叫 X」。
   - 应用监听首条入站消息（轮询 state.db 的会话/消息计数，或 gateway 日志），收到就打勾。
   - 完成 → 记 `firstrun.done`，首页恢复常态；引导期间不打扰。

「认识你」不放进应用：第一轮微信对话按 `docs/ONBOARDING.md` 走，AI 自己问、自己写 USER.md，
比表单自然，也顺便教会用户"记忆是看得见的文件"。

状态存 `%LOCALAPPDATA%\hermes\hermemory-ui.json`，不碰内核配置。

## 4. 免费模型（三个方案）

上游做法不能直接用：`nous/welcome` 是 Nous 的匿名身份 + 他们家的推理主机，国内不稳、且等于把用户
注册到别人家账号体系。

- **A. 自建试用中转（推荐，若要"免费"）**
  一台小服务器跑 OpenAI 兼容网关，按机器发试用 Key：7 天 / 30 万 tokens / 日限 200 次；
  后端用便宜模型（DeepSeek / qwen-flash）。EXE 点「免费试用」自动写入 base_url + key。
  到期前一天托盘提醒"填自己的 Key 继续用"。
  成本粗算（估算）：30 万 tokens ≈ ¥0.3–1/人，1000 个名额 ≈ ¥300–1000；需要域名、限流、
  机器指纹 + 微信绑定后才发，防薅。
- **B. 不做免费，只做"零配置推荐"（零成本）**
  默认选中 DeepSeek，给「去申请 Key」按钮（打开官网）+ 回来粘贴。转化率低一些，但当天能上线。
- **C. 本地模型当免费**：一键 llama.cpp，下载 2–5 GB，只适合当"完全离线"卖点，不适合首次体验。

建议：**先 B 上线；A 用 1000 个名额小规模试**；C 放 P2。

## 5. 插件/技能市场（我们的形式）

**数据源**：直接读内核 `plugin-catalog` 的 YAML（本地、离线、有 SHA），不调 CLI 列表
（`plugins list` 实测会卡住渲染大表格）。

**货架**：不做 600 个全量，做精选 30–50 个，中文重写：
- 记忆增强（memory 65 里挑 8–10）：标注"数据会发到第三方"的必须显式披露。
- 工具与自动化：搜索、日历、提醒、RSS、翻译。
- 模型与代理：额外 provider、失败降级。
- 桌面类（141 个）全部隐藏——我们用不上。

**页面**：分类标签 + 搜索 + 卡片（中文名 / 一句话 / 作者 / 版本 / 需要填的 Key / 权限 / 数据去向）
+ 已装列表（启用、停用、卸载、检查更新）。

**安装链路**：读 YAML → `plugins show <name>` 取依赖与能力 → 中文确认框 →
`plugins install <name> --yes-deps --enable` → 进度 → 刷新 → 提示"微信里已经能用"。

**安全**：
- 只允许目录内条目，SHA 固定；任意 Git URL 收进"开发者模式"。
- 展示 `capabilities`（工具/钩子/中间件）和 `requires_env`，用中文说人话。
- `tier=community` 默认折叠警告；体检页加"已装插件安全审计"（`hermes security`）。
- `requires_hermes` 不满足的置灰。

**国内网络**：安装走 git clone GitHub。做镜像开关（自建代理或 Gitee 镜像仓），失败回落官方；
Top 10 插件可考虑把源码打进 Setup（+几 MB）。

**技能先上**：技能是纯 markdown、无依赖、不执行代码，风险低；先做 10–15 个中文技能
（备忘整理、日程、写作、翻译、菜谱、旅行），再上插件。

## 6. 其它 P0/P1

- **P0 应用内更新**：检查 → 下载 → 校验 → 静默升级（复用 Setup 的升级路径，保留记忆）→ 重启；
  加"稳定 / 尝鲜"通道。不再只是"打开浏览器"。
- **P0 模型与额度页**：`hermes usage` + 预设 + 测通；首页状态卡显示"本月剩余/限流恢复时间"（有端点才显示）。
- **P1 自动清理**：`sessions.auto_prune` 开关（默认 90 天）+「立即清理」+ 当前对话数与占用。
- **P1 诊断包**：一键打包日志/配置（脱敏）给客服。
- **P2 离线模式 / 多微信号（profiles）**。

## 7. 排期（估算）

| 阶段 | 内容 | 工作量 |
|---|---|---|
| 0 | 定方案（免费试用与否）、插件白名单、文案 | 1–2 天 |
| 1 | 首启 3 步（写配置、测 Key、扫码、首条消息检测） | 3–5 天 |
| 2 | 插件/技能市场（货架、安装、披露、镜像回落） | 4–6 天 |
| 3 | 应用内更新 + 模型额度页 + 自动清理 | 2–3 天 |
| 4 | 离线模式、profiles | 视情况 |

## 8. 风险

- **插件安全**：第三方插件能把记忆发出去 → 白名单 + 披露 + SHA 固定 + 默认折叠。
- **免费试用被薅**：微信绑定后才发 + 机器指纹 + 日额 + 总量上限。
- **内核升级打架**：固定内核版本，`requires_hermes` 闸门，插件随内核回归测试。
- **与内核进程的竞态**：装插件/改配置时网关在跑 → 复用现有锁与"改完重启网关"的提示。
- **git 依赖**：内核自带 git 在 `%LOCALAPPDATA%\hermes\git`，但要确认全新机器上一定装好。
